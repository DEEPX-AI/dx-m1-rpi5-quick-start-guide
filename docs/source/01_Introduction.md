The **DEEPX DX-M1** is a middle-entry edge NPU designed for high-performance AI acceleration. This manual provides technical guidance for integrating the **DEEPX DX-M1 Accelerator Card** with the **Raspberry Pi 5** via PCIe M.2. It covers hardware architecture, driver/firmware installation, and the software setup required for AI inference, including sample applications and real-time monitoring via `dxtop`.
