The **DX-M1** (& **DX-M1M**) is an entry-to-mid level edge NPU designed for high-performance AI acceleration. This manual provides technical guidance for integrating the **DEEPX DX-M1** (& **DX-M1M**) with the **Raspberry Pi 5** via PCIe, using an M.2 module or the Sixfab AI HAT+. It covers hardware architecture, installation with thermal management, and the software setup required for AI inference, including sample applications and real-time monitoring via `dxtop`.
