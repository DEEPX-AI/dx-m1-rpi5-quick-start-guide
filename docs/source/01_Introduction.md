The **DX-M1** (& **DX-M1M**) is an entry-to-mid level edge NPU designed for high-performance AI acceleration. This manual provides technical guidance for integrating the **DEEPX DX-M1** (& **DX-M1M**) **Accelerator Card** with the **Raspberry Pi 5** via PCIe M.2. It covers hardware architecture, installation with thermal management, and the software setup required for AI inference, including sample applications and real-time monitoring via `dxtop`.
